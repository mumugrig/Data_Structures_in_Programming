# Сложност - 05.10.2026

## Алгоритъм(неформална дефиниция)

Алгоритъм ще наричаме последователност от краен брой стъпки, които решават даден проблем.

## Сложност

Думата сложност, ще свързваме с функция, която оценява изпълнението на даден алгоритъм спрямо размера на входа му.  Сложността на алгоритъм може да се разглежда в три случая:

- best case(най-добър случай);
- average case(среден случай);
- worst case(най-лош случай);

Сложността ще изразяваме със следните означения:

- $\mathcal{O}$("О-голямо") - $\mathcal{O(f(n)) = g(n)} <=> \exists c > 0 & n_0 \geq 0 : f(n) <= c * g(n) \forall n \geq n_0$
- $Theta$("Тита-голямо")

Имаме два основни вида сложност - сложност по време и сложност по памет.

### Сложност по време

Сложност по време наричаме, броя елементарни стъпки, който е нужен за изпълнението
